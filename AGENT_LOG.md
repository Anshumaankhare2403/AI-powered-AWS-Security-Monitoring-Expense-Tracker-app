### Implementation Details
1. **Dedicated MySQL 8 Database Instance**:
   - Initialized a dedicated data directory in `database/mysqldata` running on port 3307 to prevent conflicts with pre-existing Windows services.
   - Configured UTF-8 multibyte character set (`utf8mb4_unicode_ci`).
   - Created application database `expensetracker` and application user `tracker` with full privileges.
2. **Relational Database Design**:
   - Designed 8 normalized tables: `users`, `refresh_tokens`, `categories`, `transactions`, `budgets`, `savings_goals`, `goal_contributions`, and `notifications`.
   - Used `DECIMAL(12, 2)` for monetary values to prevent IEEE 754 floating-point inaccuracies.
   - Implemented strict referential integrity with foreign key cascading and compound indexing on query-heavy attributes.
3. **Database Migration Pipeline**:
   - Configured Alembic with `env.py` dynamically loading SQLAlchemy models and environment connection URLs.
   - Successfully generated and applied the initial migration `26315f61e8ab_initial_migration.py`.
4. **FastAPI Backend Setup**:
   - Built a modular structure with clean separation of concerns (`core`, `models`, `schemas`, `database`, `api`, `services`).
   - Implemented lifespan event that verifies MySQL connectivity on startup and seeds default categories.
   - Implemented `/health` and `/` endpoints.
5. **React + Vite Frontend Setup**:

### Errors Encountered & Fixes Applied
1. **Error**: Windows Defender Application Control (WDAC) blocked unsigned Cython DLLs (`_collections_cy`) when using pre-release SQLAlchemy 2.1.9 on Python 3.15.
   - **Fix**: Switched the virtual environment to the installed stable Python 3.11 (`C:\Users\anshu\AppData\Local\Programs\Python\Python311\python.exe`) and pinned `SQLAlchemy>=2.0.28,<2.1.0`. All imports and database operations executed cleanly without DLL blockages.
2. **Error**: Direct execution of `.\venv\Scripts\pytest.exe` was blocked by WDAC because generated `.exe` launchers outside system directories require special execution permissions.
   - **Fix**: Executed test suite using the standard Python module runner: `.\venv\Scripts\python.exe -m pytest -v`.
3. **Error**: Existing MySQL service on port 3306 was locked with non-default administrative credentials.
   - **Fix**: Initialized a dedicated, portable MySQL 8 instance located at `database/mysqldata` on port 3307 with user `tracker` and password `trackerpass`. Configured both local configuration and Docker compose to support this setup.
