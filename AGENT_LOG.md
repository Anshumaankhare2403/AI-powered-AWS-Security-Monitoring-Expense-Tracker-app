### Errors Encountered & Fixes Applied
1. **Error**: Windows Defender Application Control (WDAC) blocked unsigned Cython DLLs (`_collections_cy`) when using pre-release SQLAlchemy 2.1.9 on Python 3.15.
   - **Fix**: Switched the virtual environment to the installed stable Python 3.11 (`C:\Users\anshu\AppData\Local\Programs\Python\Python311\python.exe`) and pinned `SQLAlchemy>=2.0.28,<2.1.0`. All imports and database operations executed cleanly without DLL blockages.
2. **Error**: Direct execution of `.\venv\Scripts\pytest.exe` was blocked by WDAC because generated `.exe` launchers outside system directories require special execution permissions.
   - **Fix**: Executed test suite using the standard Python module runner: `.\venv\Scripts\python.exe -m pytest -v`.
3. **Error**: Existing MySQL service on port 3306 was locked with non-default administrative credentials.
   - **Fix**: Initialized a dedicated, portable MySQL 8 instance located at `database/mysqldata` on port 3307 with user `tracker` and password `trackerpass`. Configured both local configuration and Docker compose to support this setup.
